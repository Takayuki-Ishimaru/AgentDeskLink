# 対応環境と既知の制限

**日本語** | [English](KNOWN_ISSUES_en.md)

対象バージョン: `0.1.5`

ベータ版として、利用範囲を限定して提供します。すべてのアプリや OS 構成での動作を保証するものではありません。

## 対応環境

| 環境 | 利用範囲と条件 |
| --- | --- |
| macOS 14 以上 / Apple silicon | ブラウザとデスクトップ。アクセシビリティ権限が必要で、画像取得には画面収録権限も必要 |
| Windows 11 x64 | ブラウザとデスクトップ。対象アプリと同じ対話セッションで実行 |
| Linux x64（Ubuntu 24.04） | ブラウザ操作。Chrome / Chromium の実行に必要な共有ライブラリと OS sandbox が必要 |
| macOS x64 / Windows arm64 / Linux arm64 | この共通 VSIX の対象外 |

同じ OS でも、アプリや表示倍率、モニター構成によって利用できる操作が異なる場合があります。共通 VSIX の対応対象に自分の OS・CPU が含まれていることを確認してください。

このリリースでは、macOS / Apple silicon、Windows x64、Linux x64 で同じ VSIX を利用します。Linux のデスクトップ操作には対応していません。Ubuntu 24.04 以外のディストリビューションでの動作は未確認です。

Ubuntu のユーザー名前空間制限により、自動取得した Chromium は追加の sandbox 設定が必要になる場合があります。[Linux の準備](INSTALL.md#os-ごとの準備)を確認してください。

## アプリと入力

- アプリの状態確認・起動・通常終了は macOS と Windows で、CLI のポリシーによる明示許可が必要です。VS Code 拡張の既定設定では、この起動・終了機能は有効にしません。Windows では専用の Win32 デスクトップに起動します。既存の人間のアプリをそのデスクトップへ移動しません。
- 終了できるのは本サーバーが起動した許可対象だけです。人間が起動した個体、前面の個体、編集中の文書がある個体の終了や強制終了は行いません。
- 背面での意味的操作も、アプリ自身の遅延動作まで含めた完全な非干渉は保証しません。
- 物理入力を利用するには `interactive_desktop` モードを指定します。人間と同じマウス・キーボードを使うため、並行作業中には使用しないでください。
- デスクトップのスワイプはスクロール方式です。OS の実タッチ接点を提供するものではありません。
- MCP の有効化、対象の許可、権限段階、物理入力、無加工画像は別々の設定です。個別承認はブラウザの main document にある検査可能な操作に限られ、ネイティブアプリ・iframe・Shadow DOM 内への昇格は未対応です。既存の `allowAllOperations: true` は権限段階より優先されます。CLI の制限は指定したポリシーに従います。
- helper の通信が取消し・タイムアウトで中断すると、セッションが無効になる場合があります。MCP サーバーを明示的に再起動し、対象の取得からやり直してください。

- 緊急停止は拡張が管理するサーバーに適用され、すでにアプリへ渡った処理を取り消すものではありません。手動起動したサーバーは、その MCP ホストで停止してください。

## ブラウザの承認と手動操作

- 承認で許可する通信は、内容を検査できる URL encoded フォーム POST 1 回です。multipart・ファイル・一般的な AJAX/DELETE は対象外です。ページの処理が内容を変更した場合も拒否します。
- VS Code に接続できない場合や、許可したネイティブ操作で確認画面自体を操作できる構成では、個別承認を利用できません。
- 手動ログインの通信許可は現在の origin に最大 120 秒適用されます。その間はサイト処理による送信・変更・削除も可能です。自動操作は停止しますが、再開・失効は送信済み処理を取り消しません。
- 座標クリックは最新の保持画像と同じ対象・位置を必要とし、画像取得から 30 秒以内に限られます。ページが変わった場合は画像を取得し直してください。

[操作設定と承認](OPERATIONS.md)も確認してください。

## 画像とプライバシー

VS Code 拡張のブラウザ画像は許可した origin が対象です。ネイティブ画像は別途明示許可が必要です。CLI ではポリシーで画像取得を許可します。ブラウザでは iframe・閉じた Shadow DOM・明示保護領域・検出した秘密ラベルや本文の秘密パターンをマスクします。通常の入力欄や checkbox は画像で確認できます。`redacted: true` はマスク処理の実施を示し、画像全体の秘密検出を保証しません。`redaction.scope` と `redaction.methods` で処理範囲を確認できます。画像やテキスト内の未知の秘密情報を完全に検出する保証はありません。MCP で返した情報は AI ホストへ渡るため、取得を許可する対象を確認してください。

ブラウザの `data-adl-sensitive`、`data-adl-classification="SECRET"` / `"UNKNOWN"` は子孫にも適用され、子の `PUBLIC` 指定では解除できません。観測では保護対象の内容をマスクし、通常のcontrol許可リストによる領域内の操作を拒否します。画像と保持フレームのcropにもマスクを適用します。祖先・ラベルの走査上限内で安全性を確認できない場合も保護対象として扱います。

selectの候補一覧が応答予算を超える場合は項目名・現在値・選択状態を優先し、候補の省略を要素の `options_truncated: true` で示します。`scope: "id:<element_id>"` と大きな `token_budget` で再取得するか、`include` から `options` を外してください。候補は最大100件です。この取得上限や候補内の文字数上限に達した場合も同じフラグを返します。最後のcursorページの `truncated: false` は、前のページの要素で候補が省略されていないことを保証しません。

連続フレームの取得は可能ですが、音声、エンコード済み動画、自動的な定期撮影には対応していません。

## 配布と更新

- Windows の helper は未署名、macOS の helper は ad-hoc 署名です。macOS の公証には対応していません。
- 更新元は GitHub の公式リポジトリに固定されており、設定は不要です。
- 利用する OS・CPU に対応する版がまだ公開されていない場合は、更新の確認だけを行い、インストールは行いません。
- 認証が必要な配布先からの自動更新には対応していません。必要な場合は手動で VSIX をインストールしてください。
- 更新後はウィンドウの再読み込みが必要です。作業中に自動で再読み込みすることはありません。

詳しくは[インストール手順](INSTALL.md)と[更新ガイド](UPDATES.md)を参照してください。AgentDeskLink は [MIT License](../LICENSE) で提供します。同梱する第三者ソフトウェアには、それぞれのライセンスが適用されます。


## 問題の報告

配布元が案内する窓口へ、OS・CPU、AgentDeskLink と VS Code の版、再現手順、エラーコードを伝えてください。設定パネルの「ログを開く」、またはコマンドパレットの「AgentDeskLink: ログを開く / Open Logs」で関連するエラーを確認できます。個人情報、認証情報、画面本文、入力値を含むログや画像は送らないでください。

操作を止める場合は、VS Code の MCP 管理画面でサーバーを停止してから、ワークスペースの MCP 有効化をオフにしてください。
