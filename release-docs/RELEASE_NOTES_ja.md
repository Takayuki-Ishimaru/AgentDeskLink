# AgentDeskLink 0.1.3（ベータ版）

**日本語** | [English](RELEASE_NOTES_en.md)

AI エージェントから、MCP を通じてローカルのブラウザとデスクトップを操作するベータ版です。利用前に[対応環境と既知の制限](KNOWN_ISSUES.md)を確認してください。

## 0.1.2 からの主な変更

- macOS / Apple silicon、Windows x64、Linux x64 で同じ VSIX を利用できるようにしました。各 OS 用の Node.js と画像処理ライブラリ、macOS/Windows 用 helper を同梱し、起動時に対応するランタイムを選びます。
- MCP の有効化と操作権限を分けました。ブラウザの origin、対象アプリ、操作権限、物理入力、無加工のネイティブ画像を個別に設定できます。有効化だけでは対象へのアクセスを許可しません。
- 指定した範囲の画面差分、要素名、選択肢、日本語ラベルの読み取りを改善しました。ブラウザでは階層を指定して読み取れます。
- ブラウザ画像で、秘密情報を示すラベルや本文のパターンをマスクする処理を改善しました。
- `adl_observe` に任意の `representation: "auto"` を追加しました。応答サイズに応じて全体表示と差分表示を選び、全体に切り替わる場合は `reset: true` を返します。
- 別のブラウザセッションが応答を待っている間も、他のセッションを処理できるようにしました。
- macOS と Windows の画面要素の読み取りと、背面操作時の状態確認を改善しました。
- 導入と更新の日英ガイドを現行の設定に合わせて更新しました。

## 主な機能

- 画面の要素と変更部分を読み取り、クリック・文字入力・選択・スクロールを実行します。同じアプリの複数ウィンドウも個別に扱います。
- `adl_capture` でブラウザや対象ウィンドウの画像を取得し、保持した画像を切り抜いて確認できます。
- `adl_gesture` でブラウザのドラッグやタッチスワイプ、`adl_record` で時刻付きの連続フレームを取得できます。
- `interactive_desktop` では実際のマウス・キーボードを使います。`adl_prepare_input` で対象を確認してから `adl_commit_input` で実行します。準備時にもポインターが動くため、人間の操作と並行して使わないでください。
- CLI のポリシーで明示的に許可した macOS/Windows アプリでは、`adl_applications` と `adl_app` による状態確認・起動・通常終了を利用できます。

## 導入と更新

VS Code 1.101 以上で、共通パッケージ `agentdesklink-0.1.3.vsix` を「拡張機能: VSIXからのインストール」で開きます。Node.js の別途インストールや helper のビルドは不要です。インストール後はウィンドウを再読み込みしてください。

0.1.2 以前の更新機能は新しい共通ファイル名に対応していません。この版への更新は、リリースページから共通 VSIX と `SHA256SUMS` を取得し、ハッシュを確認して手動でインストールしてください。0.1.3 以降では、公式 GitHub リリースの共通 VSIX から更新を確認します。

更新後は、許可する origin／アプリと操作権限を設定し直してください。MCP の有効化だけでは操作できません。物理入力と無加工のネイティブ画像は既定で無効です。

詳しくは[インストール手順](INSTALL.md)と[更新ガイド](UPDATES.md)を参照してください。

## 利用上の注意

MCP は既定で無効です。接続を有効にしても、対象へのアクセスや操作権限は追加されません。許可する origin／アプリ、操作権限、物理入力、無加工のネイティブ画像をワークスペース設定で個別に指定してください。重要操作を個別に承認する専用 UI はありません。AI に任せる対象と操作を確認してください。

- 画像やテキストに含まれる未知の秘密情報を完全に検出する保証はありません。取得した情報は接続先の AI ホストへ渡ります。
- 緊急停止は、すでにアプリへ渡った処理や入力を取り消せません。
- macOS のデスクトップ操作にはアクセシビリティ権限、画像取得には画面収録権限が必要です。
- Windows の helper は未署名、macOS の helper は ad-hoc 署名です。
- Linux はブラウザ操作のみで、Chromium の OS sandbox が動作する環境が必要です。
