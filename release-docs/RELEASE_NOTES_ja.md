# AgentDeskLink 0.1.12（ベータ版）

**日本語** | [English](RELEASE_NOTES_en.md)

AgentDeskLink は、AI エージェントが MCP を通じてローカルのブラウザとデスクトップを操作できる VS Code 拡張機能です。

## 0.1.11 からの主な変更

- **更新時の権限設定を見直しました。** 以前の設定や起動記録がある環境では、明示した設定を引き継ぎ、省略された権限に旧版の制限付き既定値を適用します。初回セットアップの既定値は全操作です。更新後は設定パネルの「現在の実効権限」で、操作段階と URL・アプリの範囲を確認できます。
- **ブラウザの個人情報マスクを改善しました。** 氏名欄と判定された選択リストは、選択中の値に加えて候補名と値も伏せます。候補検索にも同じ保護を適用します。電話番号は、ハイフン付き、区切りのないラベル付き、全角表記に対応します。
- **観測項目をまとめて指定できます。** `adl_observe` の `include` は、公開されているすべての項目を受け付けます。
- **ブラウザとデスクトップの権限表示を分けました。** ブラウザの標準モードでは保存通信を止め、都度承認では操作中の保存通信を承認できます。デスクトップでは、都度承認は削除・送信などの重要操作に適用され、アプリの通常操作で保存や自動保存が起きることがあります。制限モードから「全操作」へ手動で切り替える場合は確認画面が表示されます。
- **承認後に残りの手順を再開しやすくしました。** バッチ中のブラウザ書き込みが保留されると、`adl_task` が承認待ちと要求 ID を返します。書き込みが解放されたら、再観測し、示された位置から残りの手順を新しいバッチで実行します。ページの自動保存が遮断された場合は、ページの保存ボタンを使う手順を案内します。
- **同梱ランタイムとライブラリを更新しました。** Node.js 24.22.2 と Playwright 1.65.0 を使用します。Chromium の実行ファイルが見つからない場合と、サンドボックスが起動しない場合を区別して報告します。

## 導入と更新

VS Code 1.101 以上で、`agentdesklink-0.1.12.vsix` を「拡張機能: VSIX からのインストール」で開きます。共通 VSIX は macOS の Apple silicon、Windows x64、Linux x64 に対応します。手動更新では `SHA256SUMS` でハッシュを確認し、インストール後にウィンドウを再読み込みしてください。

自動更新は段階的に届く場合があります。0.1.2 以前からは手動インストールが必要です。セットアップ、更新、操作権限については、[インストールガイド](INSTALL.md)、[更新ガイド](UPDATES.md)、[操作設定と承認](OPERATIONS.md)を参照してください。
