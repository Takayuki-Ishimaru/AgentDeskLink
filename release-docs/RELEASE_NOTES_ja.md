# AgentDeskLink 0.1.4（ベータ版）

**日本語** | [English](RELEASE_NOTES_en.md)

AI エージェントから、MCP を通じてローカルのブラウザとデスクトップを操作するベータ版です。利用前に[対応環境と既知の制限](KNOWN_ISSUES.md)を確認してください。

## 0.1.3 からの主な変更

- **AIクライアントへの一括接続**を追加しました。設定パネルから Claude Code、Claude Desktop、Codex、Cursor、Windsurf、Devin、Gemini CLI、Cline、Roo Code の標準設定を検出し、MCP を登録・解除できます。VS Code の MCP も同時に切り替えます。
- 外部クライアントには、最後に一括有効にしたワークスペースの権限を適用します。既存の別サーバーや同名の手動登録は保持し、登録状態・競合・エラーを表示します。無効化・権限変更・緊急停止で古い管理対象接続を失効させます。
- 設定パネルに**現在の実効権限**と、利用条件を満たさない理由を表示します。不正な権限設定では対象の設定名と必要な形式を案内し、修正されるまで権限を拒否します。
- ブラウザの秘密情報を含む領域の保護を改善しました。`data-adl-sensitive` と `data-adl-classification="SECRET"` / `"UNKNOWN"` は子孫にも適用され、子の `PUBLIC` 指定では解除できません。観測・画像・保持画像の切り抜きに保護を適用し、保護領域内の通常操作を拒否します。
- 選択肢が観測の応答サイズに収まらない場合は、項目名と現在の状態を優先し、`options_truncated: true` で候補の省略を知らせます。候補の取得上限に達した場合も同じフラグを返します。
- URL を開く際のキャンセル、バッチ操作、アプリ終了後の状態整理、サーバー停止の処理を修正しました。更新確認を中止した直後に手動で再確認した場合の処理も改善しました。
- AIクライアントへの接続方法と解除手順を含め、日英の導入ガイドを更新しました。

## 導入と更新

VS Code 1.101 以上で、共通パッケージ `agentdesklink-0.1.4.vsix` を「拡張機能: VSIXからのインストール」で開きます。macOS / Apple silicon、Windows x64、Linux x64 で同じ VSIX を利用できます。Node.js と画像処理ライブラリ、macOS/Windows 用 helper を同梱し、起動時に対応するランタイムを選びます。インストール後はウィンドウを再読み込みしてください。

0.1.3 の更新機能は共通 VSIX に対応しています。更新確認・自動更新の設定に従って取得するか、リリースページから VSIX と `SHA256SUMS` を取得し、ハッシュを確認して手動でインストールしてください。0.1.2 以前からは手動インストールが必要です。

他の AI クライアントへの登録は自動では有効になりません。許可する origin／アプリと操作権限を確認したうえで、設定パネルの **AIクライアント → すべて有効** を選んでください。反映には各クライアントでの再接続・新しい会話・再起動が必要な場合があります。ユーザー設定への登録のため、他のプロジェクトからも選択したワークスペースの許可範囲を利用できます。Codex の TOML 設定は値を保持して再整形します。標準外の設定保存先は自動登録の対象外です。

詳しくは[インストール手順](INSTALL.md)と[更新ガイド](UPDATES.md)を参照してください。

## 利用上の注意

- MCP は既定で無効です。有効化だけでは対象へのアクセスや操作権限を追加しません。重要操作を個別に承認する専用 UI はありません。
- 物理入力と無加工のネイティブ画像は既定で無効です。`interactive_desktop` は実際のマウス・キーボードを使うため、人間の操作と並行して利用しないでください。
- 画像やテキストに含まれる未知の秘密情報を完全に検出する保証はありません。取得した情報は接続先の AI ホストへ渡ります。
- 緊急停止は、すでにアプリへ渡った処理や入力を取り消せません。
- macOS のデスクトップ操作にはアクセシビリティ権限、画像取得には画面収録権限が必要です。
- Windows の helper は未署名、macOS の helper は ad-hoc 署名です。
- Linux はブラウザ操作のみです。Ubuntu 24.04 x64 で、Chrome / Chromium に必要な共有ライブラリと OS sandbox が動作する環境が必要です。
- 拡張機能を削除する前に **すべて無効** で外部クライアントの管理対象登録を解除してください。
