# AgentDeskLink 0.1.10（ベータ版）

**日本語** | [English](RELEASE_NOTES_en.md)

AI エージェントから、MCP を通じてローカルのブラウザとデスクトップを操作するベータ版です。利用前に[対応環境と既知の制限](KNOWN_ISSUES.md)を確認してください。

## 0.1.9 からの主な変更

- **GitHub などのページを読み取る互換経路を追加しました。** 初回の DOM API 検証に通らない文書は、ページの JavaScript と分離した DOM API で読み取ります。`read_only: true` のセッションでは本文・検索・ページ移動を利用でき、入力・クリック・スクロール・画像取得・手動引き継ぎは拒否します。個人情報のマスクと通信制限は維持します。
- **深いページ構造と長い目次の先にある本文を読みやすくしました。** DOM は最大 64 階層まで取得します。既定の全量観測に本文への入口となる `landmarks` を返し、`text` や `within:<element_id>` で必要な本文に進めます。取得元の上限による省略は `source_limits` で区別します。
- **隠し本文を除外し、操作ラベルを読み取りやすくしました。** 非表示・透明・極小の本文は返さず、除外を `hidden_text: true` で示します。スクリーンリーダー用の正当な操作ラベルは名前として保持します。このフラグだけでページに悪意があるとは判断できません。
- **日本語の個人情報マスクを改善しました。** 郵便番号、番地を含む住所、ラベル付きの氏名・住所、フォームのラベルや autocomplete を使う入力値の保護を追加しました。ラベルのない任意の氏名・住所をすべて識別できるわけではありません。`allowPersonalData` を有効にしても、認証情報と明示保護領域は引き続き保護します。
- **デスクトップの終了・破棄も承認の対象にしました。** Close / Quit / Exit / Discard / Do not save などは、通常操作モードでは拒否し、都度承認モードでは実行前に確認します。操作後に対象が消えても、フォーカスの変化だけでアプリが終了したとは判断せず、対象一覧を確認してください。
- **承認画面の内容を整理しました。** VS Code の表示言語に合わせて日本語または英語で表示します。ブラウザの操作には近くの行・項目・ダイアログなどの説明を補足します。これはページ側の説明であり、送信先の処理対象を保証するものではありません。保護領域・隠し本文・入力値は補足から除きます。
- **操作を続けるための診断を改善しました。** 通信の接続失敗とポリシーによる遮断を区別し、古い状態への操作では現在の revision を返します。対象ごとのジェスチャ対応範囲も確認できます。エラー後は画面を観測し直し、同じ操作を重複実行しないようにしてください。

## 互換読み取りの範囲

互換経路のセッションは読み取り専用のままで、権限を変更しても入力操作には切り替わりません。子 iframe の本文は取得せず、`source_limits` の `frame_unavailable` で示します。通常の経路で既に観測した同じ文書が後から改変された場合は、`untrusted_dom_api` で停止します。

保存通信の個別承認と、信頼するサイトへの最長 30 分間の継続許可は引き続き利用できます。対象と制限は[操作設定と承認](OPERATIONS.md)・[対応環境と既知の制限](KNOWN_ISSUES.md)を参照してください。

## 導入と更新

VS Code 1.101 以上で、共通パッケージ `agentdesklink-0.1.10.vsix` を「拡張機能: VSIXからのインストール」で開きます。macOS / Apple silicon、Windows x64、Linux x64 で同じ VSIX を利用できます。Node.js・画像処理ライブラリ・各 OS 用のデスクトップ helper を同梱します。Linux の helper には OS 側の Python 3 と AT-SPI2 関連パッケージが必要です。インストール後はウィンドウを再読み込みしてください。

0.1.3〜0.1.9 からは更新確認・自動更新を利用できます。自動更新は段階的に届く場合があります。手動の場合は VSIX と `SHA256SUMS` を取得し、ハッシュを確認してからインストールしてください。0.1.2 以前からは手動インストールが必要です。

**既存の `agentdesklink.allowAllOperations: true` は更新後も優先されます。** 段階的な権限へ切り替えるには、設定パネルで読み取り専用・標準・都度承認を選び直してください。MCP の有効化だけでは対象へのアクセス権限を追加しません。

他の AI クライアントは **AIクライアント → すべて有効** で登録します。選んだワークスペースの権限が共有され、他のプロジェクトからもその範囲を利用できます。更新・権限変更・VS Code の再起動後は、必要に応じて再接続してください。

[インストール手順](INSTALL.md)・[更新ガイド](UPDATES.md)を参照してください。

## 利用上の注意

- 個別承認には VS Code への接続が必要です。対象・入力内容・観測した状態が変わった場合は、観測し直してください。閉じた Shadow DOM と別プロセスの iframe の個別承認は未対応です。
- Linux の操作可否はアプリとデスクトップ環境に依存します。画像取得・物理入力・アプリの起動と終了は未対応です。別のウィンドウやアプリがアクティブになった場合はセッションを閉じ、`desktop_focus_changed` を返します。
- 手動ログインの通信許可中には、サイトのスクリプトも送信・変更・削除を行えます。再開・期限終了・緊急停止は送信済み処理を取り消せません。
- 物理入力と無加工のネイティブ画像は既定で無効です。`interactive_desktop` は実際のマウス・キーボードを使うため、人間の操作と並行して利用しないでください。
- 画像やテキスト内の未知の秘密情報を完全に検出する保証はありません。取得した情報は接続先の AI ホストへ渡ります。
- macOS のデスクトップ操作にはアクセシビリティ権限、画像取得には画面収録権限が必要です。Windows の helper は未署名、macOS の helper は ad-hoc 署名です。
- 拡張機能を削除する前に **すべて無効** で外部クライアントの管理対象登録を解除してください。
