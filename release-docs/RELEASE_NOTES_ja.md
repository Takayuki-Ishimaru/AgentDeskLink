# AgentDeskLink 0.1.9（ベータ版）

**日本語** | [English](RELEASE_NOTES_en.md)

AI エージェントから、MCP を通じてローカルのブラウザとデスクトップを操作するベータ版です。利用前に[対応環境と既知の制限](KNOWN_ISSUES.md)を確認してください。

## 0.1.8 からの主な変更

- **Web アプリの保存通信を個別に承認できるようになりました。** 都度承認モードでは、操作中にページが送る fetch / XHR の書き込みを送信前に保留します。確認画面でメソッド・URL・本文（秘密情報は伏せます）を確認し、承認した通信だけを送れます。AI は `adl_approvals` で結果を待ち、同じ操作を繰り返す必要はありません。
- **サイトへの書き込みを継続して許可できます。** 確認画面の「このサイトへの書き込みを続けて許可」で、同じ VS Code ウィンドウの AI サーバーから同じ送信先 origin への対象通信を最長 30 分間許可できます。許可はチャットをまたいで有効になり、設定パネルで確認・取り消しできます。認証情報を含む通信や、購入・支払いなどと判定される操作は対象外です。詳細は下記を確認してください。
- **保存されていない状態を明示します。** 書き込みが遮断された操作には `write_blocked: true` を返します。通常操作モードでは書き込み通信を引き続き遮断するため、画面に変更が見えても保存されていない場合があります。
- **操作後の差分と警告を読み取りやすくしました。** 操作が始めた通信と画面の変化が落ち着くまで最長 400 ミリ秒待って差分を返します。警告は一度だけ報告し、操作応答にはその操作に対応する警告を含めます。
- **GET の検索フォームは承認なしで利用できます。** 検索フォームと判定できる GET の送信は、通常操作・都度承認モードで利用できます。POST、認証情報を含むフォーム、削除などの重要操作はこの例外に含みません。
- **Delete ボタンの承認を整理しました。** Delete / Remove / 削除だけが理由で重要操作になるボタンは、都度承認モードでも通信を制限して実行し、書き込みが発生したときにその内容を確認します。購入や送信など、ほかの重要操作はボタンの操作自体にも確認が必要です。
- **必要な範囲の読み取りとスクロールを改善しました。** `adl_observe` の `scope: "within:<element_id>"` で要素の内側に絞れます。main・article・名前付き section と、リンクを含む段落を読み取りやすくしました。スクロールできない対象と、すでに端に達した対象を区別して返します。
- **Linux のタブ切替と選択を改善しました。** GTK のタブ切替で同じウィンドウ内のフォーカスが移っても、セッションを維持して `focus_moved` を返します。次の操作前には観測し直してください。コンボボックス・リスト・タブリストは `select` の `value` で選択肢の名前を指定できます。重要な選択肢は直接その要素を指定します。

## 保存の承認とサイトへの継続許可

書き込みの保留は、メインフレームから同じ origin または許可した origin へ送る POST・PUT・PATCH・DELETE が対象です。本文なし、または 64 KiB 以下の JSON・URL encoded・text/plain を扱います。multipart・ファイル・バイナリ・ストリーム本文・同期 XHR・ビーコン・iframe からの書き込みなどは保留できず、遮断します。タイマーや自動保存など、操作の外で始まる書き込みも遮断します。保存は明示的な操作で起動してください。

保留した通信を承認すると、その通信を送ります。拒否・期限切れ・ページ遷移・ページ側の中断・緊急停止では破棄します。送信済みの通信は取り消せません。`ok: true` は入力操作の受付を示すもので、保存やサイト上の処理完了を保証しません。

サイトへの継続許可は、設定・フォルダーの信頼の変更、緊急停止、拡張機能の再読み込み、取り消し、期限終了で失効します。重要なボタンを押す前の確認、GET フォームの承認が必要な送信、複数 origin にまたがる書き込みの組は継続許可の対象外です。認証情報や購入・支払いなどの除外判定は、サイトのラベルや URL による最善努力の分類です。継続許可中は AI が対象サイトへ確認なしで書き込めるため、信頼できるサイトでだけ利用してください。

詳しい対象範囲と手順は[操作設定と承認](OPERATIONS.md)・[対応環境と既知の制限](KNOWN_ISSUES.md)を参照してください。

## 導入と更新

VS Code 1.101 以上で、共通パッケージ `agentdesklink-0.1.9.vsix` を「拡張機能: VSIXからのインストール」で開きます。macOS / Apple silicon、Windows x64、Linux x64 で同じ VSIX を利用できます。Node.js・画像処理ライブラリ・各 OS 用のデスクトップ helper を同梱します。Linux の helper には OS 側の Python 3 と AT-SPI2 関連パッケージが必要です。インストール後はウィンドウを再読み込みしてください。

0.1.3〜0.1.8 からは更新確認・自動更新を利用できます。自動更新は段階的に届く場合があります。手動の場合は VSIX と `SHA256SUMS` を取得し、ハッシュを確認してからインストールしてください。0.1.2 以前からは手動インストールが必要です。

**既存の `agentdesklink.allowAllOperations: true` は更新後も優先されます。** 段階的な権限へ切り替えるには、設定パネルで読み取り専用・標準・都度承認を選び直してください。MCP の有効化だけでは対象へのアクセス権限を追加しません。

他の AI クライアントは **AIクライアント → すべて有効** で登録します。選んだワークスペースの権限が共有され、他のプロジェクトからもその範囲を利用できます。更新・権限変更・VS Code の再起動後は、必要に応じて再接続してください。

[インストール手順](INSTALL.md)・[更新ガイド](UPDATES.md)を参照してください。

## 利用上の注意

- 個別承認には VS Code への接続が必要です。対象・入力内容・観測した状態が変わった場合は、観測し直してください。閉じた Shadow DOM と別プロセスの iframe の個別承認は未対応です。
- Linux の操作可否はアプリとデスクトップ環境に依存します。画像取得・物理入力・アプリの起動と終了は未対応です。別のウィンドウやアプリがアクティブになった場合はセッションを閉じ、`desktop_focus_changed` を返します。
- 手動ログインの通信許可中には、サイトのスクリプトも送信・変更・削除を行えます。再開・期限終了・緊急停止は送信済み処理を取り消せません。
- 物理入力と無加工のネイティブ画像は既定で無効です。`interactive_desktop` は実際のマウス・キーボードを使うため、人間の操作と並行して利用しないでください。
- 画像やテキスト内の未知の秘密情報を完全に検出する保証はありません。取得した情報は接続先の AI ホストへ渡ります。
- macOS のデスクトップ操作にはアクセシビリティ権限、画像取得には画面収録権限が必要です。Windows の helper は未署名、macOS の helper は ad-hoc 署名です。
- 拡張機能を削除する前に **すべて無効** で外部クライアントの管理対象登録を解除してください。
